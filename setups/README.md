# Info
Collection of setups, i.e. trackers configurations.\
Every setup:
* is run via ***docker-compose***
* contains docker-compose.yml describing the setup
* has ***up.sh*** script - to start the setup
* has ***down.sh*** script - to stop the setup

The next setups are ready:
* [opentrack + aitrack, works on any laptop with a web camera](opentrack_aitrack/README.md)
